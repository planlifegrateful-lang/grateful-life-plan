# Install Grateful Life OS in 10 Minutes

1. Copy the main table from README.md into Notes / Notion / Journal.  
2. Set two alarms:  
   - **Morning** (after Fajr): Read today’s quote + speak 3 specific blessings.  
   - **Night** (before sleep): Which quote did I need most? Speak its language out loud.  
3. Add the hardship/ease line as a phone wallpaper or lock-screen text.  
4. When stress hits: 10-second pause → speak the line.  
5. Optional: Open 30-DAY-GRATEFUL-LIFE-CALENDAR.md and start Day 1 today.

That is the entire install. No app required. No subscription. Just consistent speech + action.
